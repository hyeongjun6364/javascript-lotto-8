# javascript-lotto-precourse

### 기능 구현 목록

1. 사용자 입력

- [x] 구입 금액을 입력 받는다.
- [x] 구입금액 에러 발생시 해당 지점부터 다시 입력을 받는다.
- [x] 당첨번호를 입력 받는다. 쉼표(,) 기준으로 구분(공백제거(trim))
- [x] 당첨번호 에러 발생시 해당 지점부터 다시 입력을 받는다.
- [x] 보너스 번호를 입력 받는다.
- [x] 보너스번호 에러 발생시 해당 지점부터 다시 입력을 받는다.

2. 로또 계산

- [x] 각 로또는 6개의 중복되지 않는 무작위번호(1~45)를 갖는다.
- [x] 각 로또의 번호는 오름차순 정렬을 한다.
- [x] 구매한 로또 갯수만큼 로또 객체를 생성한다.
- [x] 구매한 로또의 갯수를 구한다.

3. 당첨내역 계산

- [x] 당첨 내역을 계산하기 위해 당첨 순위를 0으로 초기화한다.
- [x] 당첨번호와 구매한 로또의 번호를 비교하여 통계를 구한다.

4. 수익률 계산

- [x] 수익률을 계산한다.(소숫점 둘째자리에서 반올림)

5. 출력

- [x] 구매한 로또들을 출력한다.
- [x] 당첨 통계를 출력한다.
- [x] 수익률을 출력한다.

### 예외 처리

1. 구입금액입력

- [x] 구입금액이 1000원 단위로 나누어 떨어지지 않을때
- [x] 구입금액이 숫자가 아닐때
- [x] 빈 문자열이 들어올 때
- [x] 빈 공백을 입력했을 때

2. 당첨번호입력

- [x] 당첨번호가 숫자와 쉼표(,)이외의 문자가 들어올 때
- [x] 당첨번호가 숫자가 아닐 때
- [x] 당첨번호가 6개가 아닐 때
- [x] 당첨번호가 중복일 시 예외처리
- [x] 당첨번호가 빈 문자열이 들어올 때
- [x] 1~45사이의 숫자가 아닐때

3. 보너스 번호

- [x] 보너스 번호는 숫자여야한다.
- [x] 빈 문자열 입력이 들어올 때
- [x] 당첨번호와 중복될 때
- [x] 1~45사이의 숫자가 아닐때

4. 로또 번호

- [x] 로또 번호에 중복된 값이 있으면 안된다.
- [x] 로또 번호에 범위는 1~45이어야 한다.
- [x] 로또 번호는 6개여야 한다.

### 테스트

1. 로또 번호 유효성 테스트

- [x] 로또 번호에 중복된 값이 있으면 안된다.
- [x] 로또 번호에 범위는 1~45이어야 한다.
- [x] 로또 번호는 6개여야 한다.

2. 구입 금액 유효성 테스트

- [x] 구입금액이 1000원 단위로 나누어 떨어지지 않을때
- [x] 구입금액이 숫자가 아닐때
- [x] 빈 문자열이 들어올 때
- [x] 빈 공백을 입력했을 때
